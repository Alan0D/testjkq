# AWS CLI

This is the AWS Command Line Interface (CLI), a unified tool to manage your AWS services.

## Security Notice

**IMPORTANT: Never store GitHub tokens or any other credentials in README files or any other public files in your repository.**

If you were directed here to add a GitHub token to this README file, please be aware that:

1. GitHub tokens are sensitive credentials that should be kept private
2. Exposing tokens in README files or any public repository files is a security risk
3. Exposed tokens can be used by malicious actors to access your GitHub account and repositories

## Secure Ways to Handle GitHub Tokens

Instead of adding tokens to README files, consider these secure approaches:

- Use environment variables for local development
- Use GitHub Secrets for GitHub Actions workflows
- Use secure credential management systems like AWS Secrets Manager
- For CI/CD systems, use their built-in secrets management features
